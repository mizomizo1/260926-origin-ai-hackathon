# Career Compass Trial

仕事を選ぶ前に、短いJob Trialを体験しながら自分に合う仕事や企業を見つける、キャリア探索アプリです。

学生向けの体験フローと、企業向けのMission管理・学生管理画面を含む、ハッカソン向けのフロントエンドプロトタイプです。現在はバックエンドや本番認証を使用せず、画面遷移とモックデータで一連の体験を再現しています。

## 技術スタック

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- React Bootstrap Icons

## 必要な環境

- Node.js 22以上
- pnpm 10以上

バージョンは `.mise.toml` にも定義されています。miseを利用している場合は、プロジェクトルートで次のコマンドを実行できます。

```bash
mise install
```

## セットアップ

リポジトリを取得したあと、依存パッケージをインストールします。

```bash
pnpm install
```

## 開発サーバーの起動

```bash
pnpm dev
```

ブラウザで表示されたURLを開いてください。通常は `http://localhost:8443` で起動します。

ポートを変更する場合は `PORT` を指定します。

```bash
PORT=3000 pnpm dev
```

## プロダクションビルド

TypeScriptとViteによる本番用ビルドを実行します。成果物は `dist/` に出力されます。

```bash
pnpm build
```

ビルドした成果物をローカルで確認する場合は、次のコマンドを実行します。

```bash
pnpm preview
```

## フォーマット

Oxfmtでソースコードを整形します。

```bash
pnpm format
```

## 主な画面フロー

### 学生

1. Splash / オンボーディング
2. ロール選択・学生ログイン
3. プロフィール設定
4. A/B形式の価値観質問
5. おすすめMissionの確認
6. Mission体験
7. 振り返り・結果更新
8. Company Match、Scout Inbox、Career Passportの確認

### 企業

1. 企業ログイン
2. 企業ダッシュボード
3. 企業プロフィール設定
4. Mission作成・一覧・分析
5. 学生一覧・学生詳細
6. スカウト管理・スカウト作成

## ディレクトリ構成

```text
src/
├── App.tsx                 # 画面状態と画面遷移
├── main.tsx                # Reactのエントリーポイント
├── index.css               # Tailwind CSSとグローバルスタイル
├── components/             # 複数画面で利用する共通コンポーネント
├── data/                   # モックデータ
├── state/                  # 体験フロー用の状態・モックデータ
└── screens/                # 学生・企業向けの各画面
```

画面遷移は `src/App.tsx` の `Screen` 型と `navigate` 関数で管理しています。新しい画面を追加する場合は、画面コンポーネントの作成に加えて、`Screen` 型と `renderScreen` の分岐も更新してください。

## データと認証について

- 現在のログイン処理はデモ用です。
- データは主に `src/data/` と `src/state/` のモックデータを利用しています。
- Missionの体験結果やプロフィールは、実際のサーバーへ保存されません。
- 本番利用にはAPI、データベース、認証、入力バリデーション、エラーハンドリングの追加が必要です。

## Figma Make環境について

このプロジェクトはFigma Make向けの設定を含んでいます。Figma Make環境では開発サーバーが自動起動するため、通常は手動でサーバーを起動する必要はありません。ローカルで開発する場合は、上記の `pnpm dev` を使用してください。
